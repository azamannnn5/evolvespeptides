# Extracted data (source: evolvepeptides.com, 2026-10-14)

- catalog.json: everything per product (108): name, slug, SKU, group, size, prices, sale, stock, all image URLs, chemical info, compound facts. Also lists the 3 real site categories and the derived subcategories.
- catalog.csv: same products as a flat sheet (open in Excel or Sheets).
- site-info.json: navigation, promos, shipping, returns, testing, affiliate and wholesale facts, product page layout.
- ../catalog.js: the same catalog for the static site (window.CATALOG, window.SITE_CATEGORIES, window.SUBCATEGORIES).
- ../products.js: the 8 Best Sellers from the original homepage, in the shape main.js already uses.

Notes
- The original site has only 3 categories (Peptides 108, Capsules 8, Research Accessories 1) and no subcategories. The "subcategory" and "group" fields are derived here and can be edited.
- Each size is its own product on the source site. "group" ties sizes of the same compound together.
- "description" is empty on purpose. Product description copy was not copied; write the client's own. Factual data (CAS, formula, molecular weight, sequence, contents) is kept.
- Image URLs point at the source site. Download and replace them with the client's own photos before launch.
- 15 products were sold out at extraction time (in_stock = false).

## Site build
Pages are generated by `tools/build-site.js` (run `node tools/build-site.js .` from the project root; reads data/catalog.json). Product images are local in `images/products/`; site images in `images/site/`. Descriptions are blank placeholders (`[EDIT: ...]`) for your own copy.
Note: the product photos, hero and lab-report images carry the source brand's branding, so replace them before launch.
